# SamePace logo

The mark is **In step**: two people leaning forward at the same 14° angle. Same lean, same pace. The wordmark is lowercase `samepace` in Outfit SemiBold, with `pace` in the accent green.

Everything here is generated by `brand/build.py`. Change the geometry or colours there and rebuild; do not hand-edit the outputs.

```bash
cd mobile && npm install && cd ..
python3 brand/build.py
```

Needs `fonttools` (`pip install fonttools`) and `rsvg-convert` (`brew install librsvg`).

## Which file to use

| Use | File |
| --- | --- |
| App Store / Play Store icon | `png/app-icon-1024.png` |
| Icon shown with rounded corners (decks, web) | `svg/app-icon.svg` |
| Header or footer on a dark page | `svg/lockup-horizontal-on-dark.svg` |
| Header or footer on a light page | `svg/lockup-horizontal-on-light.svg` |
| Square or narrow spaces, social avatars | `svg/lockup-stacked-on-*.svg` |
| One-colour print, embossing, watermarks | `svg/*-mono-white.svg`, `svg/*-mono-black.svg` |
| Anything 24 px or smaller | `svg/mark-micro-*.svg`, `svg/app-icon-micro.svg` |
| Link previews (1200×630) | `svg/share-card.svg`, built to `public/og.jpg` |

The build also writes the files the apps load directly: `mobile/assets/images/*`, `mobile/assets/expo.icon/`, `public/favicon.svg` and `public/og.jpg`. The JPEG step uses macOS `sips`. In code, use `PaceMark` (`src/components/icons.tsx`, `mobile/src/components/brand.tsx`), which draws the same geometry.

## Colours

| | On dark | On light |
| --- | --- | --- |
| Left person, and `pace` | `#30D158` | `#0B7A2E` |
| Right person | `#64D2FF` | `#0B6A94` |
| `same` | `#F5F5F7` | `#111113` |
| Background | `#050506` | `#F6F6F8` |

These are the app's `accent`, `stand`, `text` and `background` tokens. The light-surface colours are darker so the mark keeps at least 3:1 contrast. Never put the bright pair on white.

## Rules

- **Clear space:** keep one head's width of empty space on every side.
- **Minimum size:** 24 px for the standard mark, 16 px for the micro mark, 96 px wide for the horizontal lockup.
- **Do not make the figures touch,** hold hands, face each other, or sit under a heart or arch. The product has no dating framing, and the logo is the first place that shows.
- **Do not recolour the figures pink and blue.** Green and blue carry no gender reading.
- **Do not change the lean, or lean the figures at different angles.** The matching angle is the idea.
- Do not add shadows, gradients or outlines, and do not set the wordmark in another typeface.
